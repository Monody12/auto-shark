Auto-Shark itself is MIT-licensed. It is designed to run alongside the
following separate programs; none of them are distributed inside this
repository or its wheels.

## TShark / Wireshark

Invoked as an external command-line program through argument-list subprocess
calls. Wireshark and TShark are distributed under the GNU General Public
License version 2 (or later) by the Wireshark Foundation. Auto-Shark does not
link against or embed Wireshark code; users install it separately. The
`probe` command records the exact version used for every analysis run.

## PySide6 / Qt for Python

Optional `gui` extra (`pip install auto-shark[gui]`, Python >= 3.11 only).
PySide6 is available under the LGPLv3/GPLv3 license family as published by
the Qt Company. The CLI core runs without it.

## External analyzers

Plugin manifests may declare third-party analyzers such as
`ctf-stego-toolkit`. Those tools run under their own licenses in isolated
job directories; their terminal output is stored verbatim as hashed evidence
and never parsed or redistributed by Auto-Shark.

## Test fixtures

`tests/fixtures/http-smoke.pcap` is a synthetic capture generated by this
project (two hand-crafted Ethernet/IPv4/TCP frames carrying one HTTP request
and one response). It contains no third-party or captured production traffic.
